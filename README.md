# Talkwise

Talkwise connects people who want to understand a topic with people willing to help. Users can choose a topic and learning intent, find a compatible partner, and continue through text, voice, or video conversations.

## MVP roadmap

- [ ] Responsive landing page and topic discovery
- [ ] Authentication and profiles with Supabase
- [ ] Topic-based matchmaking queue
- [ ] Session-based real-time text chat
- [ ] Voice and video sessions using LiveKit
- [ ] Blocking, reporting, and session feedback
- [ ] Playwright end-to-end tests

## Planned stack

- Next.js App Router, React, TypeScript
- Tailwind CSS and shadcn/ui
- Supabase Auth, PostgreSQL, and Realtime
- LiveKit for voice/video
- GitHub and Vercel
